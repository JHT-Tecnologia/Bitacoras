# Bitacoras
Bitácoras de desarrollo y proyectos.

## Cómo subir una bitácora

1. Copia [`PLANTILLA.md`](PLANTILLA.md).
2. Guárdala en `proyectos/<nombre-del-proyecto>/AAAA-MM-DD.md`
   (si hay más de una sesión el mismo día: `AAAA-MM-DD-2.md`).
3. Rellena las secciones y haz commit.

Desde GitHub web: entra a `proyectos/`, pulsa **Add file → Create new file**,
escribe la ruta `<proyecto>/AAAA-MM-DD.md` (la carpeta se crea sola) y pega la plantilla.

## Convenciones
- Nombres de proyecto en minúsculas y con guiones: `app-inventario`.
- Fechas en formato ISO (`2026-11-12`) para que se ordenen solas.
- Una entrada por sesión de trabajo, no por semana.
